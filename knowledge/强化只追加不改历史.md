# 强化只追加不改历史

## 语义

`private/software_use_only-<app>/knowledge/experience.jsonl` 是**只追加**台账：
每行一个 JSON 条目，`kind` 为 `learn` 或 `reinforce`，写入后永不改写、永不删除。

理由：附属技能的价值在于「哪次真实使用得出了什么结论」可审计、可回溯。
若允许改写，误操作与自我美化都无法发现。

## 可变的部分

只有**状态位**允许更新，且集中在 `state.json` / `index.json`：

- `confidence`：`ok` +0.1，`fail` −0.15，限幅 0~1（`su_reinforce.py`）。
- `uses`：每次 reinforce +1。
- `last_used`：刷新为本地 ISO 时间。
- `status`：`draft` / `ready` / `stale`（久未用自动降级）。

历史条目里的 `confidence` 是当时快照，不随后续变化——这是刻意的。

## 禁止

1. 用新结论覆盖旧条目（应追加一条并在 `note` 里指明修正了哪条）。
2. 删除 `experience.jsonl` 行以「整理」台账。
3. 手改 `index.json`（它是 build 产物，会被下次扫描覆盖）。
