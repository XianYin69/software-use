# knowledge（知识库）

software-use 只存「如何学软件」的元知识，不存任何具体软件操作细节。

## 条目

- [前缀命名规范](前缀命名规范.md)：`software_use_only-` + slug 的硬约束与校验点。
- [注册与发布两层模型](注册与发布两层模型.md)：注册＝强制、发布＝进私有仓（GitHub PRIVATE）；「不公开」＝仓库属性而非不入库。
- [依赖分工](依赖分工.md)：判读/输入模拟/建附属/文档核对各交哪个依赖技能与通道。
- [四阶段流程](四阶段流程.md)：learn → resolve → invoke → reinforce 的输入输出与衔接。
- [强化只追加不改历史](强化只追加不改历史.md)：experience.jsonl 的 append-only 语义与状态位。

## 边界

- 具体软件经验落在 `private/software_use_only-<app>/knowledge/`，不得复制到本目录。
- 判读方法（截图/OCR/听觉）由 camera-vision / screen-vision / audio-perception 承担。
