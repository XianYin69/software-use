# 注册强制与禁止发布

## 契约（0.2.0 反转）
附属技能 `software_use_only-*` **必须**登记进 SMS register.json——否则 SMS 索引不到、
派发不到；「不公开」指的是**不进任何 git 仓库/远端/GitHub**（内容涉侵权），不是不注册。

## register.py 的两级扫描
深度 1：`root` 自身 + `root/*`；随后深度 2：对每个候选目录扫 `private/*` 中含
`SKILL.md` 的子目录。每条 entry 附 `visibility`（frontmatter，附属缺省 PRIVATE）、
`parent`（private/ 下＝所属技能名，否则 null）、`publish`（PRIVATE＝false）。

## 三道发布闸
1. `software-use/.gitignore` 含 `private/*` + `!private/.gitkeep`；
2. `sync_skills.py` 的 `_copy()` ignore `private`——hub→客户端永不携带附属技能；
3. `su_index.py --audit` 实测 `git ls-files private` 仅 `private/.gitkeep`。

## 校验点
- `--audit`：未登记或字段不符 → `E_NOT_REGISTERED`；有被跟踪项 → `E_GIT_LEAK`；
  缺 `private/*` → `E_NO_GITIGNORE`；register 缺失/损坏 → `E_NO_REGISTER`/`E_BAD_REGISTER`。
- 附属技能被复制到 `~/.kilocode/skills` 顶层 → 会以 PUBLIC 登记且丢 `parent`，属违规。
