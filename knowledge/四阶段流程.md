# 四阶段流程

## 时序

```
真实使用取证 ─┐
              ├→ 1 learn ──→ 2 resolve ──→ 3 invoke ──→ 4 reinforce ─┐
网络检索结论 ─┘        (草稿/追加)   (命中?载入:派建)  (契约派发)   (回写索引) ┘
```

reinforce 之后回到 1，形成「在使用中变强」的闭环。

## 各阶段契约

| 阶段 | 脚本 | 输入 | 输出 |
|---|---|---|---|
| learn | `su_learn.py` | `--app --evidence --source --note` | 附属技能草稿 + `experience.jsonl` 追加 + `state.json` |
| resolve | `su_index.py --find` | 关键词 | 命中条目 JSON；未命中 `E_NOT_LEARNED` → 派 Skill_Generator |
| invoke | `su_invoke.py` | `--app` | 绝对路径 + 调用契约 + 最近经验摘要 |
| reinforce | `su_reinforce.py` | `--app --outcome --note` | 追加条目、uses+1、confidence 限幅、重建索引 |

## 取证由谁做

software-use **不判读语义**：截图/OCR 交 `screen-vision`、`camera-vision`，
声音交 `audio-perception`，文档核对交 `webfetch`，新建附属交 `Skill_Generator`。
本技能只负责把它们的产出登记为 evidence 与 source。

## 状态位

`draft`（无证据或 confidence ≤0.3）→ `ready`（有证据且 confidence >0.3）→
`stale`（`last_used` 超 90 天）。`index.json` 每次 build 重算，不手写。
