# 降级策略

## 错误码

| 码 | 出处 | 含义 | 兜底动作 |
|---|---|---|---|
| `E_NOT_REGISTERED` | `su_index.py --audit` | 附属技能未登记进 register.json 或 `visibility`/`parent`/`publish` 不符 | 跑 `register.py --write` 重扫登记；重跑 audit 至 PASS |
| `E_LEAK_TO_PUBLIC` | `su_index.py --audit` / `su_publish.py --guard` | 附属技能混入**本体公开仓**索引/暂存区 | `git rm --cached` 回退；补 ignore；重跑至 PASS |
| `E_NO_PRIVATE_REPO` | `su_index.py --audit` / `su_publish.py --guard` | `private/` 未 init 为独立私有仓＝附属技能尚未入库 | `su_publish.py --init-private --yes`（只本地，不推送） |
| `E_VISIBILITY_MISMATCH` | `su_publish.py --check-visibility` | 本体仓非 PUBLIC 或附属仓非 PRIVATE | 附属仓误公开不可撤回：立即改仓库属性并核查历史 |
| `E_NO_REMOTE` / `E_NOT_AUTHORIZED` | `su_publish.py` | 远端未配置 / 推送未带用户授权 | 照常本地 init·提交·配 remote；建仓与推送留待用户当轮授权 |
| `E_NO_GITIGNORE` / `E_NO_GIT` | `su_index.py --audit` | 缺 `private/*` ignore / git 不可用无法核验 | 补 `private/*` + `!private/.gitkeep`；装 git 后重跑，不得静默放行 |
| `E_NOT_LEARNED` | `su_index.py --find` / `su_invoke.py` | 前缀未命中 | 派 Skill_Generator 建附属技能，或先 `su_learn.py` 取证 |
| `E_NO_EVIDENCE` | `su_learn.py` | 既无 `--note` 也无 `--evidence` | 回真实使用取证（截图/OCR/日志）后重试 |
| `E_BAD_SLUG` | 各脚本 | slug 非法 | 归一化为小写 `[a-z0-9._-]` 再重试 |
| `E_NO_SKILL_MD` / `E_NAME_MISMATCH` / `E_VISIBILITY` | `su_index.py scan` | 附属技能结构不合规 | 记入 `missing[]`，rc=1，修复后重建索引 |
| `E_INDEX` / `E_LEARN` / `E_INVOKE` / `E_REINFORCE` / `E_INIT` / `E_COMMIT` / `E_INTEGRATE` / `E_PUSH` | 各脚本 | 未预期异常 | 结构化 JSON 输出 + rc=2，禁止裸 traceback |

## 降级顺序

1. 重试同一步（同类错误连续两次即视为需修复，不再原样重试）。
2. 降为 `draft`：证据不足时保留草稿，不对外宣称可用。
3. 本地优先：远端不可用（`E_NO_REMOTE`/gh 未登录）时照常本地 init/提交/配 remote，
   **不得**以「不入库」代替「不公开」。
4. 转人工：`E_NOT_REGISTERED` / `E_LEAK_TO_PUBLIC` / `E_VISIBILITY_MISMATCH` 或 `missing[]`
   无法自修时，停止编排并回报用户。

## 熔断

同一脚本同一错误累计 10 次触发惩罚熔断（见 Skill_Generator `resistance/惩罚机制`），
强制回退功能分支并求助用户。
