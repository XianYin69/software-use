# 红线约束（契约 §8）

## 八条

1. **注册强制·发布禁止**：附属技能**必须**登记进 `register.json`（`visibility=PRIVATE`、
   `parent=software-use`、`publish=false`），否则 SMS 索引不到、派发不到；但严禁进入任何
   git 仓库、commit、push、remote 或 GitHub（内容涉侵权）。`su_index.py --audit` 未登记或
   字段不符 → rc=2 `E_NOT_REGISTERED`；`git ls-files private` 除 `.gitkeep` 外有项 →
   `E_GIT_LEAK`；`.gitignore` 缺 `private/*` → `E_NO_GITIGNORE`；git 不可用 → `E_NO_GIT`；
   register.json 缺失或
   不可解析 → `E_NO_REGISTER`/`E_BAD_REGISTER`（rc=2），一律不得当作通过放行。
2. **无证据不称学会**：`evidence` 为空 → `status=draft` 且 `confidence ≤ 0.3`；
   公开文档与回报中不得写「已掌握 <软件>」。
3. **只追加不改历史**：`knowledge/experience.jsonl` 永不改写/删除既有行；
   修正结论须追加新条目并注明所改条目。
4. **写盘边界**：只允许写 `software-use/` 与其 `private/`；过程产物一律落工作区
   `tmp/`；缓存文件不得写入技能目录。
5. **不自判读语义**：画面交 `screen-vision`/`camera-vision`，声音交
   `audio-perception`，文档核对交 `webfetch`，新建附属技能交 `Skill_Generator`。

## 依赖分工红线（不自办）

6. **不得绕过安全闸**：任何真实操作必须先过 safe-mouse-automation 的 safety_gate，
   开 hud_overlay 会话留痕；遇 human_gate（验证码/登录墙/不可逆动作）立即停止并回报用户。
   禁止自调 SetForegroundWindow、禁止移动物理光标；SendInput 前台回退（
eal_input）
   须先征得用户同意。
7. **不自研输入模拟**：software-use 本体与任何附属技能都不得自己实现鼠标/键盘/拖拽/
   浏览器驱动，只能调用 safe-mouse-automation 的既有脚本通道。
8. **只引用不复制**：附属技能只能在 used_skills 里引用依赖技能 id 与其通道名，
   不得复制其代码、提示词或内部实现进本仓库（复制＝双份实现漂移且绕过安全闸）。

## 命名与结构红线

- 附属技能落 `private/`（深度 2），由 `register.py` 扫描登记；复制到顶层会丢 `parent` 并以 PUBLIC 登记，同样违反第 1 条。
- 目录名 == frontmatter `name` == `software_use_only-` + slug（小写 `[a-z0-9._-]`）。
- `index.json` 只能由 `su_index.py --build` 生成，禁止手写。

## 违规后果

附属技能未登记 → SMS 索引不到、派发不到（功能失效）；附属技能进 git/远端 → 侵权内容
不可撤回地公开；改写历史 → 经验不可审计；越界写盘 → 污染其他技能目录。任一即熔断级问题。
