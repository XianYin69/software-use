# 红线约束（契约 §8）

## 八条

1. **注册强制·发布只进私有仓**：附属技能**必须**登记 `register.json`（`visibility=PRIVATE`/
   `parent=software-use`/`publish=false`）——注册≠发布，`publish=false` 只表示不进 hub 同步与
   公开索引；同时**必须**进 `private/` 独立私有仓（GitHub **PRIVATE**）的 commit/分支/推送，
   「不公开」＝仓库可见性 PRIVATE，**禁止**以「不入库」冒充「不公开」（本次返工根因）。
   `su_index.py --audit`：未登记→`E_NOT_REGISTERED`；混入本体**公开仓**→`E_LEAK_TO_PUBLIC`；
   `private/` 未 init→`E_NO_PRIVATE_REPO`；缺 ignore→`E_NO_GITIGNORE`；git 不可用→`E_NO_GIT`；
   注册表缺失/损坏→`E_NO_REGISTER`/`E_BAD_REGISTER`（均 rc=2，不得当作通过放行）。
2. **无证据不称学会**：`evidence` 为空 → `status=draft` 且 `confidence ≤ 0.3`；公开文档与
   回报中不得写「已掌握 <软件>」。
3. **只追加不改历史**：`knowledge/experience.jsonl` 永不改写/删除既有行；修正结论须追加新条目。
4. **写盘与入库边界**：只允许写 `software-use/` 与其 `private/`（后者属私有仓工作树）；过程产物
   落工作区 `tmp/`；缓存文件不得写入技能目录。本仓 `.gitignore` 只允许临时产物、IDE 目录与
   `private/*`，**不得**排除任何本仓技能正文（git工作流约束第 7 条）。
5. **不自判读语义**：画面交 `screen-vision`/`camera-vision`，声音交 `audio-perception`，
   视频交 `video-viewer`，文档核对交 `webfetch`，新建附属技能交 `Skill_Generator`。
6. **不得绕过安全闸**：真实操作必先过 safe-mouse-automation 的 `safety_gate`、开 `hud_overlay`
   留痕；遇 `human_gate`（验证码/登录墙/不可逆动作）立即停止并回报；禁止自调
   `SetForegroundWindow`、禁止移动物理光标；`SendInput` 前台回退须先征得用户同意。
7. **不自研输入模拟**：本体与任何附属技能都不得自己实现鼠标/键盘/拖拽/浏览器驱动，只能调用
   safe-mouse-automation 的既有脚本通道。
8. **只引用不复制**：附属技能只能在 `used_skills` 里引用依赖技能 id 与通道名，不得复制其代码、
   提示词或内部实现进本仓库（复制＝双份实现漂移且绕过安全闸）。

## 命名与结构红线

- 附属技能落 `private/`（深度 2）由 `register.py` 登记；复制到顶层会丢 `parent` 并以 PUBLIC
  登记，同样违反第 1 条。
- 目录名 == frontmatter `name` == `software_use_only-` + slug（小写 `[a-z0-9._-]`）。
- `index.json` 只能由 `su_index.py --build` 生成（含本机绝对路径，两仓都不入库）。
- 可见性只落在**仓库属性＋`su_publish.py` 判定＋文档**；本体 frontmatter 不得自造
  `visibility`（`gen_agent_prompt.py` 只认 name/description/license/metadata）。
- 建仓与推送（`gh repo create` / `git push`）属远端动作，须用户当轮授权（第 9 条）；涉密仓
  必须 PRIVATE、其余 PUBLIC，建仓前先判定（第 10 条）。

## 违规后果

未登记 → SMS 索引不到、派发不到（功能失效）；混入本体公开仓 → 私有经验不可撤回地公开；
完全不入库 → 失去分支历史与回滚点；改写历史 → 经验不可审计；绕过安全闸 → 不可逆误操作。
任一即视为熔断级问题。
